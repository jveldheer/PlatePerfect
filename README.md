# 🍳 PlatePerfect

**Master Cooking Skills. Fuel Your Performance.**

PlatePerfect is a comprehensive cooking education platform designed specifically for young athletes (ages 13-25) who want to take control of their nutrition and maximize their athletic potential through proper meal preparation and cooking skills.

## 🎯 Purpose

Many young athletes struggle with nutrition because they don't know how to cook or where to start. PlatePerfect solves this by:

- Teaching fundamental cooking skills from scratch with thorough, beginner-friendly explanations
- Providing athlete-focused recipes optimized for performance, muscle recovery, and energy
- Including detailed nutritional information to help athletes understand what they're eating and why
- Offering meal prep guidance so athletes can efficiently prepare food in advance

## ✨ Features

### 📚 Cooking Skills Education
- **12+ Essential Skills** covering knife techniques, cooking methods, food safety, prep techniques, and equipment
- **Step-by-step instructions** with detailed explanations for complete novices
- **Pro tips** to help you cook like an expert
- **Common mistakes** section to help you avoid pitfalls
- **Difficulty levels** so you can progress at your own pace

### 🍽️ Athlete-Focused Recipes
- **6 comprehensive recipes** across breakfast, lunch, dinner, snacks, and pre/post-workout meals
- **Detailed nutrition facts** including protein, carbs, fats, fiber, and calories per serving
- **Athletic performance notes** explaining why each recipe benefits athletes
- **Thorough instructions** with detailed explanations for each step
- **Meal prep guidance** with storage instructions and batch cooking tips
- **Skill integration** - recipes link to the cooking skills you'll practice

### 🎨 User-Friendly Interface
- Clean, modern design optimized for readability
- Filter recipes and skills by category and difficulty
- Responsive design works on desktop, tablet, and mobile
- Intuitive navigation between related content

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd PlatePerfect
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser to `http://localhost:5173`

### Build for Production

```bash
npm run build
```

The production-ready files will be in the `dist` directory.

## 📖 How to Use PlatePerfect

### For Complete Beginners

1. **Start with Cooking Skills** - Visit the Skills page and filter by "Beginner"
2. **Learn the Basics** - Start with knife skills and food safety
3. **Practice with Simple Recipes** - Try the beginner-level recipes
4. **Build Your Confidence** - Progress to intermediate skills and recipes

### For Meal Prep

1. **Browse Recipes** - Filter by category (breakfast, lunch, dinner)
2. **Check Meal Prep Notes** - Each recipe includes batch cooking guidance
3. **Plan Your Week** - Choose 2-3 recipes that share ingredients
4. **Follow Storage Instructions** - Keep your food fresh and safe

### For Athletic Performance

1. **Understand Nutrition** - Read the "Why This Recipe for Athletes" section
2. **Pre-Workout Meals** - Filter recipes by "pre-workout" tag
3. **Post-Workout Recovery** - Look for high-protein recipes
4. **Track Your Macros** - Use the detailed nutrition information

## 🎓 Educational Approach

PlatePerfect assumes **zero prior cooking knowledge**. Every recipe and skill includes:

- **Detailed explanations** - We explain the "why" behind each step, not just the "what"
- **Visual time estimates** - Know how long each step will take
- **Skill tips** - Learn proper techniques as you cook
- **Common mistakes** - Avoid pitfalls that trip up beginners
- **Safety information** - Cook safely with proper food handling

## 🏋️ Nutrition for Athletes

Every recipe includes:

- **Complete macronutrient breakdown** - Protein, carbs, fats, and fiber
- **Calorie information** - Per serving
- **Athletic context** - When to eat it (pre-workout, post-workout, recovery)
- **Performance benefits** - Why this meal helps your training
- **Serving sizes** - Appropriate portions for athletes
